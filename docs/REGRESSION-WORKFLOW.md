## 执行规则

- 默认core：5项串行，最多一个浏览器。
- static：原1、2、3、5共四项，文档/工具改动仅跑此范围，本次约0.4秒。
- 酒狐改动再跑30；本次仅工具/文档变更，没有重复酒狐交互和性能采样。
- 涉及的JS另检查语法；失败只复跑仍启用的失败套件。
- 旧quick/full均映射core，兼容命令不会恢复停用项目。
- 已停用项目不能通过--only选中，旧失败缓存中的停用项目会被忽略。

```powershell
node tools/run-all-checks.mjs                  # 默认5项
node tools/run-all-checks.mjs --profile static # 静态4项
node tools/run-all-checks.mjs --list           # 只列清单
node tools/run-all-checks.mjs --only 1,2,3,5    # 按原编号选择
node tools/run-all-checks.mjs --only 30        # 仅酒狐
node tools/run-all-checks.mjs --failed         # 仅仍启用的失败项
```

默认验证3210实际部署，可指定http://127.0.0.1:3400/验证开发页。
shots/final/last-run.json记录实际范围与耗时；last-failures.json只保留当前启用项目的未通过记录。
部分通过不表示未执行项目通过；编号不重新分配，以免原30变成其他含义。
