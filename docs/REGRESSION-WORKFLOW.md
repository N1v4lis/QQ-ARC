## 已做的节约

CDP Page.send和浏览器命令收到响应后清除30秒/20秒超时计时器，连接关闭时也清理挂起命令。
过去没有显式process.exit的脚本在完成后仍留着计时器，导致Node空等；现在保留真正超时保护并及时退出。
单项遮挡检查上次34.204秒，本次5.75秒，断言通过。不是全量耗时或CPU/RSS改善的测量。

本次quick实测9/9通过、55秒；static5/5通过、约0.5秒。运行器用隔离临时fixture验证了失败退出码、只重跑失败、部分范围报告与未知套件拒绝。

quick固定9套：1–5、11、16、41、43。只启动4个浏览器，覆盖静态、主要外壳、首页、入口和错误。
static仅1–5，不需要运行界面；插件部署检查在不具备宿主环境时按原规则跳过。
所有模式仍串行，不以增加并发和峰值内存换速度。小改动按范围补专项；full用于发布或改动广泛时。

```powershell
# 只列清单，不启动应用或浏览器
node tools/run-all-checks.mjs --list

# 日常基础验收
node tools/run-all-checks.mjs --profile quick

# 文档/静态相关改动
node tools/run-all-checks.mjs --profile static

# 仅启动动画与酒狐；编号沿用完整列表
node tools/run-all-checks.mjs --only 6,30
node tools/run-all-checks.mjs --only startup,wine-fox

# 仅重跑上次失败项
node tools/run-all-checks.mjs --failed

# 发布前完整验收（默认仍兼容旧命令）
node tools/run-all-checks.mjs --profile full
```

可在命令中加入http://127.0.0.1:3400/验证开发页；默认3210验证实际部署。
last-run.json保存本次实际范围、耗时和逐项结果；last-failures.json保留尚未通过的失败项，
只有对应套件复跑通过才清除；quick/static不会清掉未运行套件的失败记录。
均在shots/final，Git忽略。部分检查成功不代表全部43套通过。

## 后续能进一步节约的部分

SnowLuma实时套件包含25秒SSE观察、20秒日志变化观察。只改前端外观时无需跑真实日志观察；
改日志/SSE时必须验证。未来可把固定观察改为事件驱动，保留超时兜底，或分开UI模拟事件与真实集成验收。
主题相关25/26/28/29与33/34/35/40有重叠启动和状态准备，但具体断言不完全重复；
未来可合并浏览器启动，使用独立context隔离偏好，不能直接删除历史回归断言。
固定sleep逐步换成数据与布局就绪条件；动画持续时间、情绪恢复等真正的时间语义仍需测量。
真实Electron与性能采样只在对应功能改动或发布时执行；只改文档不重启应用、不跑WebGL宠物采样。
