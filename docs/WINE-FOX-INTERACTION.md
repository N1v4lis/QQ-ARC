# 酒狐互动与双角色模型调整

> 2026-10-08最新动作规则：Extra1单次完成回idle；Extra2、5、6、7循环（设置、菜单及开心互动一致）。非idle循环动作不受闲置或动作定时器切换，直到主动互动/选择其他动作；情绪循环也不再每20秒自动换动作，生气10秒情绪结束时保留正在循环的动作。自然走跑飞抵达目标是移动完成，仍归idle；自然idle仍允许自主调度。此规则覆盖旧Extra2单次与循环两轮后结束的要求。

2026-10-07，最新自然模式、情绪与圆形互动菜单已部署；本文优先于历史三阶段记录。冷启动2秒、刷新1秒保持。

## 模型与动作

酒狐与雪狐使用 [衍生模型](../Wine_Fox/Models/Derived/README.md)。原始GUI以30fps烘焙，按120帧分为4秒gui与14秒gui2，两个模型均47片段。GUI原有全局展示骨骼将角色放大和偏移，造成半身；现在GuiRoot/MRoot沿用idle位置、旋转与尺度，Root原双倍尺度归一，身体与面部姿态关键帧保持。相机始终从idle全身拟合，避免受启动时选定动作影响。

原始GLB与Blender不改，调整发生于衍生GLB导出层；几何、材质、骨架和非GUI动作曲线保持。雪狐衍生模型一并更新，QQ主题当前只加载酒狐。菜单首项为“自然”，隐藏gui/gui2及jump，仍是45个选项（自然+44个动作）。原模型的jump片段保留，设置、点击随机池和自主活动均不会触发；旧GUI/jump偏好迁到自然。旧默认idle迁自然，已手选其他动作保留。

run、walk、fly、swim、攀爬、sleep、picnic、keyboard等持续动作循环；death只播放一次。仅“自然”允许自主活动：普通动作结束idle等待1–5秒再随机动作，持续动作一般两轮后归idle。手动循环动作持续至更改选择，手动单次动作结束保持末姿，不随机替换；Extra2按明确要求单次结束归idle且不启动自主调度。开心/菜单动作临时覆盖基础动作，结束恢复自然idle或手选动作，Extra2不会反复重播。

## 显示与互动

酒狐默认启用，但仅Minecraft主题创建模型。默认主题不显示、不加载；切离MC销毁渲染器、监听和音频，加载中切离也不会迟到创建。设置隐藏启用开关，宠物无右上角关闭按钮，保留语音、暂停、大小、位置及动作控制。

轻点随机使用现有开心动作：beg、extra2、extra5、game_win、run，jump已排除。2秒内连续3次点击生气，使用sleep、picnic、sneaking及指定语音JaNai.ogg、Sato.ogg、Mo-Ya-Da.ogg。情绪状态5秒内再点击3次恢复开心；所有来源的生气均10秒后自动恢复，呆住仍可通过多次点击恢复。

每次真实互动重新随机设置60–120秒闲置期限；超时随机变生气或呆住。生气池为sleep、picnic、sneaking；呆住池经用户确认改为picnic、sneaking、keyboard，三者都显示“ご主人様…”气泡。气泡用双份文字轨道匀速从左至右无缝循环，不打字、不淡出，不重建轨道打断文字；CSS实现并随容器移动，减弱动态效果时显示静态文字。两种情绪的动作周期统一20秒，保持动作循环后直接切换；生气10秒结束，优先于20秒动作周期，因此通常不会等到第一次切换。只有自然模式会因闲置进入随机情绪，手动选择不会被闲置调度覆盖。

自然活动中有一半机会移动，走路walk、跑动run、飞行三组等概率，飞行随机elytra_fly或fly；走跑只横向，飞行可上下移动，目标限制在界面可见区。走速70px/s、跑速160px/s、飞速110px/s，移动到达归idle并保存当前位置。自然移动、拖动Fly及情绪返回run都逐渐朝向目标，飞行另带轻微俯仰；到达后idle用最短角度指数平滑转回面向主人；平滑速率由6提高至12，约0.25秒完成95%的转角，速度加倍且不瞬间跳转。拖动/长按/暂停会中止自主移动，不新增独立渲染循环。

正常拖动超过6px进入Fly，松开恢复基础动作并保存位置。情绪状态拖动不使用Fly，松开用run跑回拖动前原位，完成恢复情绪动作或手选基础动作。拖拽按下、移动和松开均不中断正在播放的语音；新点击可切换单通道声音，关闭语音、切离MC或窗口隐藏停止声音。普通鼠标移动不做蒙皮射线，透明空白仍穿透，弹窗隔离保持。

## 气泡递增

呆住后10秒增加2个气泡，再过5秒增加4个，此后每3秒增加8个；随机散落、大小和倾斜各异，最多512个，单Canvas绘制，随机0–360°旋转；约35%为无框、无背景、不滚动的纯文字。拖拽及跑回原位保留气泡和累积进度，点击或菜单互动清空。呆住动作开始或20秒切换时随机播放death语音，遵守语音开关，拖动不中断。屏幕气泡层pointer-events:none，不拦截按钮、宠物或弹窗。

轻点、长按菜单、菜单选择或键盘互动立即清空屏幕气泡和头顶文字。单次互动不改原三次点击恢复情绪规则；若仍处于呆住，再无人互动60–120秒后才重新显示和累积。切离MC、隐藏窗口、销毁或切换手动动作也清理屏幕层。

## 长按互动菜单

按住酒狐550ms且未拖动，展开圆形菜单，包含原模型的Extra0–Extra7八个动作；超过6px移动取消长按，仍按原规则拖拽。菜单打开时停止自主活动；选动作单次播放，完成恢复基础状态，Extra2有墙钟完成保护，防止丢失mixer完成回调后卡住。长按本身不计点击，不触发生气，也不打断声音。

中心“返回”、点外部或Esc关闭菜单；Shift+F10/菜单键也可打开，方向键切换菜单焦点。菜单在视口范围内定位，与主题使用相同颜色令牌，切离主题/隐藏/销毁时一并清理。原八个Extra资源及名称未删改，未引入VRChat依赖。

## 0.4.2 惯性与高速撞边

松手取最近120ms的移动样本，速度按指数衰减。速度较低或指针已停顿时维持原放置/情绪跑回规则；高速撞边按撞击方向速度判定，阈值900px/s，触发death单次、随机播放一条death语音并保持结束姿势。边缘缓慢拖动不触发。受伤期间阻止自动动作、拖动和长按菜单；5次点击恢复自然并保存偏好，不套用原三次生气规则。每次点击重新计时，连续15秒不点击自动进入呆住，恢复头顶气泡、death语音与屏幕气泡递增。重新拖动、切离主题、隐藏均取消惯性；单通道声音不因拖动停止。
