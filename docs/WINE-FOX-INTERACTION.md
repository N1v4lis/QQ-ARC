# 酒狐互动与双角色GUI拆分

2026-10-07，按用户Roadmap实现。冷启动2秒、刷新1秒及仪表盘本轮架构保持。

## 模型

原GUI以30fps烘焙，120帧对应4秒，完整片段18秒。酒狐与雪狐分别生成衍生GLB：gui为0–120帧（4秒），gui2为120–540帧（14秒），共用120帧边界姿态，后半段时间归零。

位置：[Wine_Fox/Models/Derived](../Wine_Fox/Models/Derived/README.md)。两个角色各47个clip；原几何、骨骼、纹理和其他45个动作均未改。切分保留所有原关键帧，边界按原LINEAR/STEP与四元数球面插值补齐，避免默认骨骼仅首尾两帧的轨道失真。

原Models/GLB及Blender文件保持原始交付，旧演示页也保持原始参考版本；此次调整发生于GLB导出层，没有修改.blend里的Action。QQ运行资产分别复制为winefox.glb与snowfox.glb，当前主题互动仍只按需加载酒狐，雪狐衍生模型已备好。

gui和gui2保留在资源库，主题动作菜单隐藏两者，显示45个动作。旧偏好若选gui/gui2，迁移到idle，避免隐藏选项继续后台播放。状态中的animations保留完整库，visibleAnimations为菜单库。

## 互动

- 点击或键盘Enter/空格：从模型原有FaceMode_1始终启用的动作中随机选一个，连续点击避免重复同一个动作；播放一次并用开心表情，结束恢复用户选择的基础动作。
- 当前候选来自模型实际轨道：beg、extra2、extra5、game_win、jump、run，不新增或编造动作。
- 最新“点击开心”要求取代旧2秒三次点击生气规则；连续点击重新触发开心动作，语音单通道切换，避免堆叠播放。
- 拖动超过6px才进入Fly，防止轻点先触发飞行；拖动仍只移动位置，不改原Fly曲线。松开、取消或丢失捕获后恢复基础动作，拖动不发语音。
- 互动动作短暂覆盖“暂停动作”，结束后恢复暂停；普通暂停和隐藏仍不持续绘制。
- 窗口隐藏、关闭宠物、拖动开始或关闭语音开关，停止声音。播放失败提示可重试，身体互动保持可用。

## 语音迁入

来源E:\!!!littleMaid_PECO，完整复制到项目根Wine_Fox_PECO，原目录保留。105个文件、2571508字节，逐文件SHA256及字节相同：[清单](wine-fox-interaction/voice-manifest.json)。

完整原始语音均保留，点击使用eatSugar系列10个OGG作为互动组；必要运行副本位于app/ui/assets/wine-fox/voice。声音在用户交互时按需读取，每次只播放一个，不预解码105个文件。增加“互动语音”开关，默认开启，随宠物偏好保存；宠物关闭时不加载语音或模型。遵守现有media-src，不放宽CSP。

## 生成、验证和回退

```powershell
node tools/split-fox-gui.mjs
node tools/prepare-wine-fox.mjs
node tools/check-fox-gui-split.mjs
```

split读取不可变原GLB生成两个Derived副本；prepare复制衍生模型及语音运行子集。声音文件来源及模型许可分别保留，不将第三方素材当作代码许可。

双模型专项检查通过：47个片段、4/14秒、每个原关键帧与120帧边界数值一致、原二进制数据保留、几何/材质/非GUI动作一致。部署后core五项通过，酒狐33/33子项覆盖真实鼠标开心动作、语音实际开始播放、连续轻点、静音、动作结束恢复、拖动中Fly、松开恢复、触屏、穿透、弹窗隔离及启停。记录：[验收](wine-fox-interaction/checks.json)。浏览器证实音频进入播放状态，不冒充已用耳朵听取本机扬声器。

生成模型约7.27/7.29MiB，比原模型各增加约0.72MiB，用于切分时间与关键帧；仅启用一个酒狐渲染器，仍限制30FPS。未测实际Electron整机CPU、GPU或声音延迟，不将浏览器采样当作系统性能结论。

回退通过ui-next部署备份，原始模型和105个原音频无需恢复。当前VERSION仍0.4.01，历史Release不改；本轮没有GitHub上传授权，仅本地提交与部署。
