# QQARCFOX 0.4.4.5

发布日期：2026-10-08。UI 与本机 QQA 程序版本均更新为 0.4.4.5。

## 主题切换

- 桌面端原主题选择入口统一移至「设置 → 主题 → 亮暗」，保留亮色、暗色、跟随系统三项，不重复显示。
- 跟随系统读取 Windows 应用颜色模式，系统切换亮暗后实时更新；默认、MC 和本地独立页面均支持。手动亮暗模式保持固定。
- 右上角按钮左键仍直接切换亮暗，右键打开三项选择菜单。当前项显示勾选，点击外部或 Escape 收起，方向键、Home/End 和 Shift+F10 可操作。
- 跟随系统采用新绘制的显示器与半明半暗圆形 SVG，标题栏显示独立自动模式图标；MC 主题使用像素显示器。
- 修复旧固定 36px 高度导致主题选项图标和文字越界的问题，图标预留完整空间。

## 品牌文字

- 左上角标题及页面标题改为「QQ Agent ARCFØX」，MC 标题使用主题字体并调整字号。
- Beta 横幅第一行改为「注意！这是“QQ Agent ARCFØX”的Beta测试版本。」
- 第二行改为「Beta测试版本不代表本产品的最终质量。感谢您的理解和支持，祝你好运！」，移除 Beta 与测试之间的空格。

## 验证与部署

仅运行四项静态核心检查和本次相关浏览器定点验证：亮暗/自动选择、系统变化、右键菜单与关闭行为、默认/MC 图标和标题布局、品牌文字。未恢复 43/56 项全量检查。

已部署至本机 ui-next，宿主版本补丁支持用户指定的四段版本号。归档包含源码、工具和资源，不是完整安装器，不包含个人配置或凭据。部署使用既有 apply-ui、restore-plugin-inject、patch-host-version 和 restart-agent 工具。
