# QQARCFOX 0.4.1

酒狐互动升级：仅MC主题默认出现，提供自然模式、走跑飞时朝向目的地及快速平滑转身、长按Extra0–Extra7圆形菜单。手动选择不会被随机活动覆盖；sleep循环、death单次，Extra2结束恢复idle，jump隐藏。

呆住的picnic、sneaking、keyboard都有连续从左至右滚动的ご主人様…；继续无人互动时气泡每10秒递增，最终铺满屏幕。互动立即清空，屏幕层不拦截点击，上限192格。闲置60–120秒、情绪动作20秒周期，生气10秒结束。

包含酒狐/雪狐GUI按120帧分割与全身显示、105份原始语音及指定生气语音、拖拽不中断声音、情绪拖拽跑回原位。原始GLB/Blender和素材来源保留。

本版一并收录本地此前的仪表盘共享统计与独立卡片加载优化，冷启动2秒、刷新1秒。

验证范围：原编号1、2、3、5、30五套核心检查；行为计时采用虚拟时间补充，不恢复已停用套件。验收记录见同目录0.4.1-checks.json及../wine-fox-interaction/phase-checks.json。

这是UI源码归档，不是独立Windows安装程序；QQ Agent宿主仍0.4.0。源码包保留部署、后端补丁和开发工具；按README与docs/DEVELOPMENT.md部署至ui-next。素材许可与依赖许可见Wine_Fox及运行资源SOURCE文件。用户授权本轮与上一轮打包上传，原0.4.01 Release保留。
