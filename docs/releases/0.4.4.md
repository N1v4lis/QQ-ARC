# QQARCFOX 0.4.4

发布日期：2026-10-08。本版包含自 v0.4.3 归档以来的全部本地改动，并同步将 UI 与本机 QQA 程序版本更新为 0.4.4。

## 跨账号共享人设库

- 所有账号固定读取同一份模板库，不再由“人设库共用”开关决定可见范围；进阶中的旧开关及相关说明删除。
- 首次载入将旧账号自定义模板合并到 `DATA_DIR/shared-personas.json`，同时收录未在库中出现的当前自定义人设。名称、正文、规则完全相同的模板去重；同名但内容不同的模板保留，避免丢失。原账号配置及旧模板库保留，不覆盖当前使用人设。
- 模板名称不再附加“来自主账号”，多个账号使用稳定模板 ID。新建、复制、改名、修改和删除都操作共享库，切换账号后可看到同一份模板；跨账号使用状态仍单独显示账号、群聊或私聊。
- 写入串行执行、临时文件替换，并保留上一份共享库备份。旧内容校验防止过期列表误操作；保存记录仍按账号/编辑对象隔离，删除模板不会删除本地历史记录。
- 各账号自己的默认人设、独立会话配置、身份、模型和白名单保持隔离。更改共享模板不会直接替其他账号提交当前使用人设，需要该账号重新选用并保存。

## 页面切换与侧栏

- 移除切页时强制读取宽度的重排、旧新页面同时布局的交叉淡出，以及整页任意 class 变化触发侧栏滚动的监听方式。
- 激活导航立即反馈，数据加载放到下一帧；快速连续切换会跳过尚未开始的过期页面加载。
- 设置请求合并在途加载，导航使用 15 秒短缓存；显式刷新仍重新读取。技能/插件共享 10 秒状态缓存，重扫按钮仍执行磁盘重扫。用量首次进入完整加载，返回时更新数据而不反复重建整个页面。
- 人设与设置仍复用唯一表单。跨页搬移前清理旧页面节点，防止人设编辑器暂时按设置页布局渲染，造成额外长帧；未保存人设草稿保留在状态中。
- 侧栏展开/收起为 260 毫秒缓动，文字淡入淡出；主要图标、市场/广场入口和收起状态点固定对齐到同一列，入口保持相同行高。MC 图标保留像素风，默认皮肤的色条平滑变为圆点。
- 主视图占据固定内容视口，布局隔离；页面切换保留短淡入，避免重绘两份大型页面。

## 动效及主题覆盖

- 默认皮肤动效固定启用，移除该皮肤的动效开关；旧关闭偏好不再关闭默认皮肤动效。MC 保留此前的动效设置，系统“减弱动态效果”继续受到尊重。
- 统一按钮、设置子菜单、浮层及卡片交互反馈；人设正文、规则、身份子页补充切换动效。JavaScript 动画遵循 MC 动效偏好，不再只停止 CSS 动画。
- 本地账号管理、Skill 市场、插件市场、人设广场和落地页补齐共享亮暗色与 MC 样式；已打开的本地独立页可随存储偏好变化更新。
- 将这些本地独立页面的原内联脚本拆成外链，兼容宿主现有 `script-src 'self'` 策略，不放宽安全策略。官网远程页面的样式由官网管理，本版不更改远程网站。

## 汇总 v0.4.3 之后的人设改动

- 删除“统一使用默认人设”开关及群聊/私聊类别默认模型；会话有独立内容则使用它，空字段继承本账号默认人设/主模型，白名单继续决定回应范围。
- 身份面板简化命名，默认人设页删除旧模型说明；QQ联系人列表显示上次完整缓存时间，精确到秒。
- 模板支持查看跨账号白名单内的使用情况，使用点放大、有使用时显示蓝色；模板整框显示选中效果。
- 内置小鲸鱼的提示词只读并在保存/运行时保护，允许调整身份行为；移除名称硬编码“（默认）”。右键可以设为默认，默认项显示独立星标与描边，支持重新选用。
- 正文、附加规则、身份三栏均手动保存；保存及 Ctrl+S 只提交当前栏，全部保存提交三栏，保留其他未保存草稿。
- 记录选项包含人设名称及修改时间；默认保留 1 天、5 条，进阶可设 1–7 天及 1–20 条，启动/运行时自动清理。
- 修正弹窗关闭符号、状态点焦点轮廓、保存工具栏溢出与对齐，收紧工具栏留白。
- 修复小鲸鱼右键切换时后端缺少模块级 `PERSONAS` 导入的问题，增加安装宿主保存处理器的内存回归。

## 性能观察与验证范围

同机独立浏览器窗口 1360×900，依次进入人设、技能、插件、设置、人设、仪表盘，每页间隔约 350 毫秒：

| 指标 | 修改前 | 修改后观察值 |
|---|---:|---:|
| 一轮请求数 | 37 | 约 20（受背景轮询影响） |
| 重复滚动侧栏 | 20 次 | 0 次 |
| 设置切换同步耗时 | 109 毫秒 | 约 0 毫秒 |
| 单次切换同步耗时 | 3–109 毫秒 | 约 0–3 毫秒 |

这些数字反映本机样本，不保证其他机器相同；浏览器首次文字布局、数据请求和 MC 宠物资源加载仍有成本。本轮最后两次样本未观察到 Long Task 条目，未宣称所有布局帧均低于 16 毫秒。

验证仅运行四项静态核心检查和本次相关定点检查：共享库迁移/串行写入/冲突保护、各账号只读一致性、默认/MC 亮暗四组合的侧栏中间帧/行高/图标对齐、独立页主题、快速切页与用量首载、分栏/全部保存/历史策略、模板 CRUD、默认切换、内置保护、草稿恢复及 1360/800/480 布局。真实配置写入在浏览器检查中模拟，不恢复已停用的 43/56 项完整检查。

## 安装、归档与回退

本次 GitHub 归档为 UI 源码、资源及可复现宿主补丁，不是完整 QQA 安装器，不包含个人配置、共享人设库或凭据。运行时酒狐资源保留。

既有安装完成后，部署本版增量所需：

```powershell
node tools/patch-host-persona-inheritance.mjs
node tools/patch-host-persona-policy.mjs
node tools/patch-host-shared-personas.mjs
node tools/patch-host-version.mjs
node tools/apply-ui.mjs --apply
node tools/restore-plugin-inject.mjs
node tools/restart-agent.mjs --apply
```

补丁在宿主改动前保留备份；UI 镜像亦保留上一版。共享库有上一份备份，迁移前的账号模板保留在原配置中。回退 UI/宿主补丁时应成套恢复，旧版本无法读取新共享库后续新增的模板，必要时从共享库手动恢复，避免误认为旧配置已包含新增内容。
