# 0.1.1 实验版：迁移 0.4.5a 的界面风格

本版本在 `Rust+Slint` 分支中将归档版 0.4.5a 的桌面视觉样式重建为 Flutter 控件。Rust 继续负责业务核心，运行时无需旧 Electron/Node/WebView。旧客户端及其数据不被覆盖。

- 恢复 40px 自绘标题栏、44px 紧凑状态栏、账号选择及人设快捷入口；标题栏显示实验版本号，窗口按钮不触发主题音效。
- 主导航与设置子导航分开。默认主导航 152px、设置导航 202px；Minecraft 保留 168px 主导航及像素图标。支持收起到 60px 和 Ctrl+B。
- 对照旧版色彩令牌重建浅灰底色、蓝色选中态、深色背景、Segoe UI/中文回退字体、紧凑输入框和按钮、分隔线及卡片。
- 设置页面缩小标题和留白，API 双列业务布局继续使用现有真实核心接口；小窗口将设置导航改为横向列表，避免挤压内容。
- 保留 Minecraft 背景、字体、像素图标与大拉杆；背景先绘制对应明暗底色，避免透明壁纸叠到黑底。卡片采用适当透明度保证阅读。
- Flutter 与 Rust 版本均同步为 0.1.1；归档版 0.4.5a 的版本标记保持不变。

本次迁移的是界面风格与导航层级，不表示全部旧版功能或动画已完成迁移。启动粒子动画、酒狐、完整主题打包与所有页面的细节复刻仍未完成；功能边界见 [迁移清单](../NATIVE-FEATURE-MATRIX.md)。

验证：Rust 19 项测试、Flutter 布局/导航/主题/业务控件测试及默认 4 项静态检查。真实 QQ、模型、账号密钥不用于视觉验收。
