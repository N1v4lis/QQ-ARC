# QQARCFOX 0.4.5

发布日期：2026-10-08。变更范围：从上次已推送的 **0.4.4.5（93b3708）** 到本次发布。UI 与本机客户端统一为 **0.4.5**。

## API 与搜索：整页重构

- 将“模型 API”和“搜索服务”合并为“API与搜索”，旧搜索入口统一跳转到合并页；保存同时覆盖模型与搜索配置。
- 删除原有模型折叠选项卡、按会话选模型的迁移说明和重复入口，把提供商管理、模型目录、默认模型选择、媒体输入、计价、故障备选和搜索配置放到常显工作区。
- 左侧集中管理提供商、Base URL、API Key 和模型目录；右侧配置默认模型及媒体输入。移除重复的连接地址/密钥编辑区、整页撤销按钮与内联模型配置取消按钮。
- 提供商可添加、删除，密钥可显示、保存、清除，模型可添加、删除和拉取。保存其他提供商密钥等刷新操作保留当前选中项、模型草稿及滚动位置，避免突然跳回首项。
- 默认模型和故障备选采用按提供商分组的下拉选择，备选顺序继续用于故障重试。单会话覆盖仍在人设页设置。
- 两组左右栏统一等宽、间距和起始线；提供商按钮等宽并与 Base URL 首行对齐，媒体输入、理解方式与备选列表对齐。
- 当前内容按高度自然展开；未来内容超过最大高度时，两侧独立滚动，边界滚轮不会带动整页，右栏操作按钮保持可见。窄窗改为单列。

## 模型能力与独立媒体配置

- 模型标题、目录条目和下拉选项统一显示图片/视频能力。图片依据已有检测/能力数据，视频仅依据明确能力记录；没有依据显示“未知”，不从模型名称或用户开关推断。
- 图片、视频输入开关改为同排右对齐的简洁开关，移除重复操作提示；Minecraft 皮肤保留主题拉杆。
- 图片/视频输入开关、图片专用模型、视频专用模型和视频理解方式，按“提供商＋主模型”分别保存。
- 切到未配置的模型使用独立默认值，切回恢复原模型草稿；点击保存后重新加载也能恢复。旧的全局媒体值只迁入当前模型，不复制给所有模型。
- 保存同时更新当前运行所需字段和媒体配置档案；刷新仅在同账号、模型仍存在时恢复草稿，避免串用账号或已删除模型。

## 官方价格、模型 Logo 与用量联动

- 接入 DeepSeek、GLM、Gemini、MiMo、Qwen、Kimi、MiniMax、Anthropic、OpenAI 和 Grok / xAI 的官方公开价格来源。
- 本轮公开源拉取曾取得 494 个去重价格 ID，包含别名及非文本计费条目；该数量随官方内容变化，不代表账号可调用模型数，也不保证覆盖未公开的模型价格。
- 启动读取本地缓存并异步检查更新；成功来源每 24 小时刷新，失败来源 3 小时后重试，失败保留上次有效结果。支持手动拉取和在途请求合并；修复重复初始化错误清除价格定时器的问题。
- 官方价格仅用于匹配的 HTTPS 官方域名、端口、路径与模型品牌；中转站、近似域名和不适用的地区端点不会自动套用官方价格。
- 自定义价格按连接地址＋模型隔离，兼容旧渠道价格和通用模型价格；可批量编辑，不修改官方原表。
- 美元标准单价按参考汇率折算人民币并保留汇率日期。上下文分档、峰谷、缓存写入、按图/秒等无法安全转成单一 Token 价的条目保留参考，不把未知价当作免费。
- 官方价格目录支持厂商多选：厂商按钮与带复选框的下拉同步，无选择表示全部；保留模型搜索、分页、原始价格详情及独立官网来源链接。
- 根据模型名称匹配本地品牌 Logo，在主模型、目录、备选及价格列表中显示；Anthropic、OpenAI 使用公司 Logo。资源来源与商标说明一并归档。
- Dashboard 与用量页使用同一套有效价格解析。远程价格或自定义价格变化后，相关缓存和历史日快照按计价版本更新，首次查询按需重算，不变价格复用结果；不再长期保留旧价格估算。

## 酒狐：本地设置助手与真实拉杆交互

- 右键酒狐打开旁边的自然语言对话框，输入开关或数值需求；移除手动指定设置入口。对话框根据酒狐位置选择左右侧并约束在窗口内，随移动、缩放和内容尺寸重新定位，修复停在窗口原点的问题。
- 最终实现采用本地有限语义解析，不调用模型 API、不下载聊天模型。支持设置别名、开/关、数值与中文百分比、相对增减、秒至毫秒换算、接续上一项，以及最多六项组合指令。
- 从既有设置页面生成控件目录，支持从仪表盘等页面识别开机自启等设置，执行时再导航并检查实际控件；不读取密钥、人设正文或聊天记录。
- 查询当前值不修改；无法识别、条件句、越界、重复目标等不猜测执行，给出本地提示。此前实验性的模型助手路由已移除，历史服务文件仅留作旧实现参考。
- 按距离使用 fly（超过 520px）、run（180–520px）、walk（近距离）；目标信息卡关闭时先用 use_mainhand 打开，再到控件执行动作。
- 保留酒狐正常大小，使用手部接触点预测站位及前景复制层，让酒狐在真实拉杆后方交互。动作接触时触发原控件 input/change，结束或取消恢复视觉，不改变原配置保存规则。
- 生气或呆住时直接按状态回复并拒绝工作，不发出实际操作或模型请求。取消、Escape、隐藏页面、切换皮肤及目标失效会停止后续动作。

## Minecraft 主题与页面细节

- 采用用户提供的三张背景，移除旧生成背景及缩略图；支持背景开关和可见度，不展示背景名称。
- 增加 Minecraft 动效开关；总音量及点击音、开关音、滑条音量独立相乘，修复音量滑条与百分比读数不齐。
- 修复多数页面、表头/分区和标题栏不透明底色遮住主题背景的问题；窗口关闭、最大化、最小化不再播放普通点击音。
- 不支持自定义配色的主题（包括 Minecraft）在配色内容区显示灰色遮罩并禁用编辑，标题仍可展开或收回。
- 修复会话工具 MC 图标错位及尺寸超限；整理互动音效/动效拉杆位置、活跃卡头控制组和峰谷摘要，避免启用后推动整体布局。
- 活跃卡收回时隐藏头部控制组，删除重复摘要。文本输入、下拉框和 textarea 的焦点光效在控件内部绘制，按钮/开关等焦点环内收，防止被滚动边界裁切。

## 人设与默认活跃档位

- 右侧入口改为“身份与模型设置”，说明覆盖称呼、模型和活跃档位。
- 群聊的单独活跃档位移到当前群的人设配置中，复用普通/峰谷双点滑条；时段仍沿用聊天设置。
- 身份栏“保存”或“全部保存”提交当前群的独立档位，保留其他群的配置；关闭单独设置并保存，清除当前群两类档位覆盖并恢复默认。
- 聊天设置的滑条仅编辑默认档位，补充说明并移除原群选择、当前群清除区域；统一开关仍决定是否启用各群独立档位。

## OneBot / SnowLuma 与版本同步

- OneBot 配置整理为紧凑的左右布局，启动状态及操作区移到上方，减少留白。
- 主程序启动时固定尝试拉起 SnowLuma，保留已有端口检测和异步启动过程，移除自动拉起的可编辑开关。
- VERSION 成为统一版本来源；从 0.4.5 起，apply-ui --apply 成功后自动同步本机安装目录 package.json，重启后客户端及宿主版本信息采用同一版本。
- 此次源码部署不重新打包 EXE 文件属性；发布归档为源码、工具和资源，不是完整安装器，不包含个人配置、聊天记录或凭据。后续版本同步不意味着自动上传 GitHub。

## 验证与部署

- 本轮持续使用默认/Minecraft 主题的相关浏览器定点验证，覆盖布局、厂商筛选、模型草稿、提供商刷新、群档位保存/清除及焦点环。测试中的配置修改使用模拟接口，不改真实账号设置。
- 价格解析、官方地址匹配、渠道隔离、更新调度和统计回算有对应定点检查；公开源真实拉取与合成数据验证分开记录。
- 发布检查采用用户指定的四项 static 套件及 JavaScript 语法校验，不恢复酒狐完整互动/计时检查；定点通过不代表全量回归。
- 安装使用 apply-ui、restore-plugin-inject 及专题宿主补丁（SnowLuma、价格表、助手旧路由清理），随后 restart-agent。部署前自动备份 UI 和各宿主补丁目标。
