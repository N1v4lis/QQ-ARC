# QQARCFOX 0.4.2

酒狐屏幕气泡改为单Canvas，上限512。10秒增加2个、再过5秒增加4个、之后每3秒增加8个；随机0–360°旋转，混合约35%无框无背景、文字不滚动的气泡。拖拽保留气泡与增长进度，点击互动清除。缓存字条与静止层，避免上千个页面节点，暂停/隐藏/减弱动态效果时停止持续绘制。

拖拽加入逐渐衰减的惯性；高速甩到边缘播放death单次并保持，需要点击5次恢复自然，连续15秒不点击自动进入呆住。普通情绪拖拽仍跑回原位。新增20条death语音原样保存至Wine_Fox_PECO，呆住动作开始/切换时随机播放，拖动不中断声音。

验证范围只包含原编号1、2、3、5、30及短时虚拟计时/物理边界验证，不恢复停用套件。验收数据见0.4.2-checks.json。Canvas绘制计时来自浏览器本机观察，不代表整机CPU/GPU或显存测量。

源码归档，不是独立Windows安装程序；宿主仍0.4.0。按README与docs/DEVELOPMENT.md部署到ui-next，旧ui保留。原模型及素材来源不变，许可见Wine_Fox与资源SOURCE文件；0.4.1及0.4.01历史Release保留。
