# 0.4.2-OLD

删除统一人设开关及群聊／私聊类别默认模型之前的完整源码归档。运行版本仍为 0.4.2；此归档保留旧功能，方便回退及对比。

相对上一次 GitHub 推送（v0.4.2）包含 30 次本地提交，主要变化：

- 酒狐：撞击播放 death 语音；Extra1 播放结束恢复实际 idle 姿势；Extra2 使用平滑衔接的循环片段，Extra2／5／6／7 持续循环；普通点击排除 Extra0–7，长按菜单移除 Extra0。
- Minecraft 主题：英文和数字改用本地 Monocraft，中文保留 MinecraftAE；调整混排尺寸及小字号可读性；重绘导航、主题、设置及桌面图标，缩小侧栏图标并去掉外部描边；开关采用大拉杆，导航展开收起使用开关音效。
- 人设页面：从设置中独立出来，入口置于技能上方；最终采用左侧全量群聊／好友目录、右侧正文编辑与规则／身份模型分区。右键名单操作与设置中的聊天白名单联动，红绿圆点表示状态。
- 保存与历史：名称、正文、附加规则及系统覆盖改为手动保存；支持 Ctrl+S 和短暂成功动画，显示撤销／重做快捷键；保留按账号与会话隔离的最近五次带时间保存记录，加载历史仅填入草稿。
- 模板管理：新建空模板；右键复制、重命名、删除；删除不清除最近保存历史；实际有修改才询问是否保存，再继续新建或选用。选用入口可展开／收起，点击外部也收起，并遵循开关音效设置。
- 交互修复：修正同正文不同名称模板选中不一致，系统提示词输入框始终显示，保存确认选择后立即关闭；弹窗及右键菜单增加基础动效。
- 开发与交付：新增人设库宿主补丁、定点验证及文档；后续默认仅四项静态检查，不自动执行酒狐 56 项完整检查。

验证：四项静态检查及相关人设页面、手动保存、模板库和宿主路由定点验证；真实人设与配置写入在浏览器检查中模拟。未执行已停用的完整互动检查。

本归档不包含用户运行配置、密钥或本机最近保存记录。首次安装需按项目文档部署前端并应用所需宿主补丁。
