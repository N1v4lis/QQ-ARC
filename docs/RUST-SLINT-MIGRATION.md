# Flutter＋Rust 核心迁移与酒狐方案评估

日期：2026-10-09。分支保留 Rust+Slint 名称，当前方向为 Flutter 主界面与 Rust 业务核心。旧架构归档 v0.4.5a，开发无限期暂停，恢复时间待定。迁移可行性验证通过后再停止旧架构开发，目前不宣布迁移完成。README 警告与 main 相同，正文注明最新方向。

## 当前实现

flutter/ 为 Windows 桌面 UI，native/ 为独立 Rust 进程。默认运行不依赖 Node、Electron、WebView 或 Slint。Flutter 启动核心，通过会话令牌保护的本机 HTTP 访问随机端口，关闭客户端时关闭核心。消息直接存 SQLite TEXT，JSON 用于网络协议、配置与 IPC。

每账号独立 SQLite WAL 和有界串行写队列，不同账号可并发写各自数据库。历史按 ID 游标分页，模型输入、回复与用量在同一事务提交。实验数据独立于旧客户端，不直接打开旧 V8 BLOB 数据库。

OneBot 支持正向 WS/WSS、令牌鉴权、self_id 账号隔离、echo 响应对应及手动群聊/私聊文本发送。模型支持 OpenAI 兼容 Chat Completions SSE，读取文本与实际返回的 Token 用量，按自定义输入/输出单价估算。界面等待完整响应后显示全文。密钥目前只驻留内存，不落盘、不写日志。

Flutter 接入总览、账号切换、会话、模型设置、OneBot、手动会话记忆及主题偏好。上下文暂取最近 20 条消息，历史限制 24000 字符、记忆限制 8000 字符；尚无精确 Token 预算、自动摘要或检索压缩，不宣称已实现 Token 节省目标。

## 酒狐仍在考量

候选为 Slint 承载原生 3D，或原生 3D 直接与 Flutter 合成。须验证 GLB、骨骼动画、材质、透明合成、DPI、交互定位与设备丢失恢复。开关默认关闭且禁用，不用占位图冒充完成。

启用须确认可用独显/核显，并实际创建渲染设备；CPU、未知或不可用适配器不能解锁。普通业务启动不受酒狐 GPU 检测限制。早期 slint-prototype 仅为可选候选验证，不属于默认构建，尚未完成候选构建与渲染验收。

## 验证和待办

本地 Rust 测试覆盖账号隔离、并发持久化、Unicode/NUL、分页、IPC 鉴权、Origin 拒绝、模拟 OneBot 收发及模拟模型 SSE/计价。Flutter 静态分析与控件测试覆盖页面状态、主题持久化调用和禁用的酒狐开关。测试不发送实际 QQ 或模型服务请求。

GitHub Actions 配置 Windows Flutter + Rust 构建，完整开发目录作为 artifact；实际是否通过以具体运行结果为准。目前没有安装器、干净系统部署验收或性能对比实测，不宣称开箱即用或达到某体积/占用目标。

后续验收：桌面启动与窗口生命周期；消息去重/重连、媒体/引用；旧数据受控导入与备份；模型取消、增量显示、多模态、工具和搜索；完整价格/用量；人设、插件、技能、主题包；酒狐；运行库、许可证、更新/卸载。现有 JS 插件不视为可直接在 Rust 中运行。所有迁移改动仅推送新分支，不覆盖归档客户端。

## 首个 Windows 开发包验证（2026-10-09）

Flutter Windows Release 与 Rust Release 已在本机实际构建成功；Flutter 分析无问题，控件测试及已编译核心的启动/持久化/重开测试通过。独立客户端已实际打开并检查主题页和禁用的酒狐开关；关闭窗口后确认 UI 和核心进程退出。开发目录附带 VC 运行库，当前包约 35 MiB、ZIP 约 15.3 MiB。这是本次构建实测，不代表安装器或未来完整版体积，也没有完成干净 Windows 部署或完整旧版功能验收。

原客户端的开机自启已关闭，配置与启动项备份仅保留本地，不提交；后续本机开发使用新分支。工具链安装在用户指定的工作区外位置，README 不记录本机路径。构建脚本检查分支并生成独立输出，普通开发包不注册开机自启。
