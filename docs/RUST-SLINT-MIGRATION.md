# Flutter＋Rust 核心迁移与酒狐方案评估

日期：2026-10-09。分支保留 Rust+Slint 名称，当前方向为 Flutter 主界面与 Rust 业务核心。旧架构归档 v0.4.5a，开发无限期暂停，恢复时间待定。迁移可行性验证通过后再停止旧架构开发，目前不宣布迁移完成。README 警告与 main 相同，正文注明最新方向。

## 当前实现

本轮按旧版 79 接口、32 组配置尝试移植业务和全部页面入口，酒狐排除。Flutter 界面、Windows runner、Rust 网络/业务/账号 SQL 存储独立运行；不启动旧客户端业务后端。密钥已由早期仅驻留内存改为 Windows DPAPI 加密保存。

已接通账号隔离、OneBot 文本及默认关闭的自动回复、白名单/屏蔽、响应档位/峰谷、人设、提供商目录与文本模型工具链、搜索/网页/代理、价格目录与站点/模型单价、SQL 存档/记忆/用量、纯提示词技能、社区基础查询、SnowLuma 外部进程管理、托盘及显式自启。详细状态以 [功能迁移清单](NATIVE-FEATURE-MATRIX.md) 为准。

**未完成全部旧版功能。** 实时媒体、完整工具及 JS 插件、主动话题、主题包、完整市场安装发布、多 QQ 注入登录、历史重算与无损旧库迁入仍在后续清单。界面上的媒体配置只按模型保存草稿，不能当作媒体推理已经工作。未执行的进阶选项不开放为可用功能。

不同账号独立 SQLite WAL 和写队列；收件与去重同事务，模型成功用量逐请求记录，手动完整对话正文成对事务。正常文本是 SQL TEXT，JSON 用于协议/配置和显式官方副本导入。上下文为可调最近消息/字符上限，还没有精确 Token 预算、摘要和检索压缩。

QQAF 核心不依赖 Node/Electron/WebView/Slint。启动用户自带 SnowLuma 会使用外部组件自己的运行时；这不等于整个 QQ＋OneBot 环境不存在 Node。实验程序不直接打开旧库、读取旧密钥或覆盖原安装。

## 酒狐仍在考量

候选为 Slint 承载原生 3D，或原生 3D 直接与 Flutter 合成。须验证 GLB、骨骼动画、材质、透明合成、DPI、交互定位与设备丢失恢复。开关默认关闭且禁用，不用占位图冒充完成。

启用须确认可用独显/核显，并实际创建渲染设备；CPU、未知或不可用适配器不能解锁。普通业务启动不受酒狐 GPU 检测限制。早期 slint-prototype 仅为可选候选验证，不属于默认构建，尚未完成候选构建与渲染验收。

## 验证和待办

Rust 单元与模拟集成测试、Flutter 分析/控件测试及实际核心进程测试分开检查。当前测试项与实现边界见功能清单；不向实际 QQ/模型发送消息，不以第三方 mock 代替真实兼容验收。

仓库含 Windows 构建工作流文件，实际运行结果须另行确认，不宣称 GitHub CI 已通过。开发目录带 VC 运行库和素材许可；安装器、干净系统部署与性能对比未完成。所有迁移推送仅到 Rust+Slint，不向 main 合并，不新建 Release。

## 首个 Windows 开发包验证（2026-10-09）

Flutter Windows Release 与 Rust Release 已在本机实际构建成功；Flutter 分析无问题，控件测试及已编译核心的启动/持久化/重开测试通过。独立客户端已实际打开并检查主题页和禁用的酒狐开关；关闭窗口后确认 UI 和核心进程退出。开发目录附带 VC 运行库，当前包约 35 MiB、ZIP 约 15.3 MiB。这是本次构建实测，不代表安装器或未来完整版体积，也没有完成干净 Windows 部署或完整旧版功能验收。

原客户端的开机自启已关闭，配置与启动项备份仅保留本地，不提交；后续本机开发使用新分支。工具链安装在用户指定的工作区外位置，README 不记录本机路径。构建脚本检查分支并生成独立输出，普通开发包不注册开机自启。
