# 独立人设页

2026-10-08：用户要求将人设移出设置，并置于侧边栏技能正上方。

主导航新增persona页签和view-persona；默认皮肤为角色卡线稿，MC皮肤为原创16格狐脸角色卡。
设置二级菜单移除人设，顶栏人设/模型入口与旧openSettingsSection('persona')统一跳转独立页。

人设页复用原有统一/分会话编辑、模板选择与添加删除、模型配置、自动保存和撤销。
全局仅一个settings-form，switchTab将它移入当前设置/人设视图，不复制ID或监听器。
离开两种编辑页时先flushSettingsSaves；renderSettingsSection和saveConfig依据persona主路由选择人设分支。
这样在刚输入后立即切页时，仍先收集并保存旧表单。设置的其他分区选择保持。
人设模板加载保留customRules，避免选择模板时丢掉其附加规则。

侧边栏字体由16px回调至14px，包括展开收起和底部社区入口；卡片说明与刻度字号不变。
