# 独立人设页

2026-10-08：用户要求将人设移出设置，并置于侧边栏技能正上方。

主导航新增persona页签和view-persona；默认皮肤为角色卡线稿，MC皮肤为原创16格狐脸角色卡。
设置二级菜单移除人设，顶栏人设/模型入口与旧openSettingsSection('persona')统一跳转独立页。

人设页复用原有统一/分会话编辑、模板选择与添加删除、模型配置、自动保存和撤销。
全局仅一个settings-form，switchTab将它移入当前设置/人设视图，不复制ID或监听器。
离开两种编辑页时先flushSettingsSaves；renderSettingsSection和saveConfig依据persona主路由选择人设分支。
这样在刚输入后立即切页时，仍先收集并保存旧表单。设置的其他分区选择保持。
人设模板加载保留customRules，避免选择模板时丢掉其附加规则。

## 独立列表与编辑布局（2026-10-08）

最新要求：人设参考技能、插件页面，不再使用信息卡。页面采用相同usage-head标题栏，显示添加入口、人设数量与自动保存说明；下方为常显的人设库和编辑器。库内用列表显示名称、内置/自定义标识与正文摘要，搜索名称及完整内容，不触发配置保存。点击列表条目将正文与customRules一起填入编辑器，并沿用自动保存，原选择弹窗入口仍保留。

统一/分会话模式、名字、展示名、参与度、角色正文、附加规则、系统提示词覆盖、默认群聊/私聊模型、分会话弹窗仍保留。分会话模式中添加按钮禁用，可通过全局人设设置弹窗编辑兜底配置。人设页完全退出autoFoldSettings流程，分会话模型区也使用直接标题，不生成setcard；唯一表单仅用于复用数据与保存契约，不沿用设置页面布局。

宽窗列表/编辑器并排，980px以下上下排列；模板列表自身滚动，编辑区跟随页面滚动。默认与MC皮肤共享布局，MC字体/拉杆保留。撤销按钮放在独立页标题行，模板切换、编辑和分会话切换沿用现有保存逻辑。

侧边栏字体由16px回调至14px，包括展开收起和底部社区入口；卡片说明与刻度字号不变。
