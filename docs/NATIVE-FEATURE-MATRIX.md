# Flutter＋Rust 功能迁移清单

RS0.2.0 的增量实现与剩余事项见 [当前验收进度](RS0.2.0-ACCEPTANCE.md)；下表记录迁移起点，已更新项以当前进度为准。

页面迁移与本轮 UI 验收详见 [Flutter UI 清单](FLUTTER-UI-MIGRATION.md)。

2026-10-09，`Rust+Slint` 实验分支。用户要求尝试迁移全部功能与 UI，酒狐除外。本轮从旧版源码核对 79 个 HTTP 接口及 32 组默认配置；清单是实现边界，不是“79 个接口已全部移植”的声明。新核心不沿用旧 URL，按照业务重新划分模块。

“已接通”表示本地实现及模拟链路可工作；“部分”表示同一功能仍有未移植行为；“待迁移”表示执行链路没有实现。第三方真实 QQ、模型、社区登录及更新安装未完成端到端验收。

## 底层与运行约束

每账号一个 SQLite WAL 库及容量 256 的写队列，不同账号并发写各自库。正常正文/记忆/用量使用 SQL 字段，不把消息全量 JSON 序列化保存。当前实时 OneBot 只保存 raw_message 正文；媒体/引用关联表用于显式导入，不能据此宣称实时多媒体已经接通。

自动回复首次关闭，需用户保存 runtime.enabled。白名单决定是否响应，屏蔽名单决定可否记录/响应。每会话同时只运行一个任务并保留一个最新待处理事件；消息先存 SQL，再合并唤醒，不以任务合并丢掉历史。最多 256 个会话任务，单账号并发 1–16；等待和发送不会持有全局网络锁。容量已满时不新增任务，尚无完整背压告警 UI。

每个成功返回的模型请求立即记录 Token 和输入/输出估算，后续网络/工具错误不会删除已发生的计费。完成的手动对话两条正文单独成对事务提交；自动 QQ 回复使用已经记录的收件，不重复写入用户消息。默认上下文 80 条，可配置至 500，历史 24000 字符、记忆 8000 字符；没有精确 Token 预算和自动压缩，不声称已经减少 Token 或超越旧版性能。

故障备选只发生在首轮且未执行工具之前；一次发送超时不自动重试。finish 会结束处理并抑制自动发送模型附带正文。手动模型测试中的 send_message 仅返回预览，不发送到 QQ。

密钥使用 Windows DPAPI 加密保存到独立账号 preferences，普通配置禁止明文密钥字段。此实现不是跨设备密钥同步；非 Windows 保险库待迁移。IPC 为随机令牌保护的回环 HTTP，不提供旧版任意公网监听。

网络、配置、IPC 和模型工具参数仍使用协议要求的 JSON；用户禁止的是正常存储的消息 JSON 文档往返，并非禁止这些协议本身。外部 SnowLuma 自带 node.exe 属于独立组件，不是 QQAF 的业务后端。

## 源码盘点与后续验收

旧接口完整列表： [legacy-routes.txt](../native/resources/legacy-routes.txt)。默认字段与公开内置人设： [default-config.json](../native/resources/default-config.json)、[personas.json](../native/resources/personas.json)。它们来自源码默认值，没有读取用户配置或密钥。

32 组字段的处理：api/providers 为新原生模型链；dshProviderKeys 换保险库；providersSourceYaml 待迁移；webSearch/security 为搜索及公共网页链；snowluma 为连接与外部组件管理；persona/customPersonas/personaByChat 为人设与共享模板；allow/deny/allowAllWhenEmpty/blocklist/globalBlocklist 为响应/屏蔽；wakeDelayMs/maxConcurrentRuns/send/store/commandMute 部分参与调度；drainDelayMs/sessionRetryAttempts/proactive/chatActive/sticker/communityExemptions/memory 的自动处理待迁移；tools/skills 为已实现工具与纯提示词技能；extensions 仅清单；server/ui 换原生桌面偏好。未知/未执行参数不能以“可以保存”为完成依据。

当前测试覆盖 SQLite 并发与重开、鉴权/Origin、模拟 OneBot echo、模型 SSE、工具轮次与备选、Claude/Gemini 协议、账号凭据、并发配置合并、内置人设权限、消息持久去重、官方导入回滚及技能兼容边界。Flutter 检查页面状态、媒体草稿切换、空安装首个账号、禁用酒狐及实际核心进程。测试不发送实际 QQ 或模型请求。

下一步必须逐项补齐本表待迁移链路，再做真实第三方服务、完整 UI、干净 Windows、数据备份/迁移及性能验收。实验包构建成功不能当作全部功能验收通过。
