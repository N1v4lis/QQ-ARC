# 窗口与核心异步启动

2026-10-07，按用户“窗口、SnowLuma核心、插件应该异步加载”实施。仅本地落地，未经用户明确允许不上传GitHub，不改0.4.01归档。

## 实现

`tools/patch-host-async-startup.mjs`为安装宿主electron/main.js、src/app.js添加幂等补丁，全部锚点验证后写入；原文件分别完整备份，失败时回滚。本项目不复制整个安装版后端或覆盖其余定制。

core.start新增可选onListening及signal，保留返回端口时核心初始化已完成的原契约，兼容无参数调用。实际HTTP绑定后回调立即创建窗口和托盘，采用真正绑定的端口，随后让出事件循环。Electron仍等待核心完成以捕获错误，但这份等待不再挡住窗口。

插件与SnowLuma继续并行，OneBot连接及提醒循环仍在两者准备结束后安排，不提前接入消息。启动端口判断直接探测，不使用8秒状态负缓存。状态接口原有缓存保留。

7日用量预热和会话索引对账推迟至核心完成30秒后，避开首屏4秒动画，退出时清除计时器。用量解析分片由50文件缩为8文件；未删除档案、插件或动画。索引使用既有缓存，外部新增/删除文件的对账因此会推迟约30秒；用量页主动打开仍会按需计算。

新增经过鉴权和来源校验的GET /api/startup，提供ready、plugins、snowluma状态。初始化期间API写操作返回503/CORE_STARTING并附Retry-After，避免手动操作与插件、自动启动互相竞争；只读状态和页面正常加载。后台完成后恢复正常操作，界面动画不等待账号扫码登录。

退出时AbortController取消初始化，等待启动链退出后再core.stop，防止退出清理后后台任务又建立连接、watcher或计时器。保留原有错误弹窗；主动退出造成的取消不作为启动失败弹窗。

## 测量

一次完整退出再启动，从main.js探针执行起计时，不含双击到进程装载的时间，不代表所有机器或清空文件缓存后的磁盘基准。

| 阶段 | 优化前普通启动 | 本次异步启动 |
|---|---:|---:|
| HTTP开始监听 | 1.833秒 | 1.295秒 |
| 窗口显示 | 11.980秒 | **1.716秒** |
| 页面加载完成 | 12.292秒 | 2.075秒 |
| 插件加载耗时 | 7.635秒 | 1.146秒 |
| SnowLuma准备耗时 | 9.653秒 | 1.149秒 |
| 核心完成 | 11.587秒 | 2.581秒 |

37个插件全部加载，/api/startup确认plugins=ready、snowluma=ready、ready=true。窗口在两者加载期间已显示。采样、文件缓存和系统负载影响具体秒数；窗口不再等待后台完成的顺序变化由事件记录直接确认。4秒冷启动/2.6秒刷新动画及六阶段未改，因此窗口出现与进入主界面是两个时间。

清除临时探针后的普通重启复核：boot-diag记录main入口19:59:12.646、窗口显示19:59:15.322（2.676秒）、核心完成19:59:16.464（3.818秒），再次确认先显示窗口、后完成核心；/api/startup三项均就绪。两次实际窗口约1.7–2.7秒，没有声称每次固定1.7秒。

原始事件：[异步启动](cold-startup/profile-async.jsonl)。历史诊断见 [优化前诊断](COLD-STARTUP-DIAGNOSIS.md)。

## 验证与维护

`node tools/check-async-startup.mjs`在隔离上下文执行安装版实际start函数：后台未完成即收到真实端口（3210占用时3211）、OneBot等待两者、启动直接探测、预热推迟、Abort取消不启动连接/预热、补丁幂等及锚点拒绝。它是本次生命周期专项，不加入自动回归，也不恢复用户停用套件。

宿主JS与工具语法检查、static四项及实际重启测量；工具profile-host-startup兼容旧/新顺序，探针结束逐字节还原源码，之后普通重启清除内存探针。没有修改UI文件，无需镜像部署或重跑酒狐。

宿主重装后需重新运行补丁并检查源码锚点；备份后缀为.bak-async-startup-时间戳。回退须先退出QQ Agent，再将对应两份备份恢复并重启。
