# 0.4.5a → Flutter UI 迁移与验收

2026-10-09，实验分支 `Rust+Slint`，客户端 0.1.1。酒狐排除。运行界面不依赖 Electron、Node 或 WebView。参照的是归档源码与用户已认可的布局，而不是重新设计页面。

## 验收边界

当前是页面结构和可用交互的迁移构建，尚不能宣称与 0.4.5a 全部 UI/功能无差别：完整工具事件时间线、全部图表字段、成员/文档记忆、完整模板管理、启动明暗细节、所有音效/弹窗及第三方服务仍需要逐项对照。Flutter 字体栅格化也有自然差异。

业务缺口仍以 [功能清单](NATIVE-FEATURE-MATRIX.md) 为准。界面覆盖、控件测试和构建成功不能替代干净 Windows、真实 OneBot、实际模型与完整旧功能验收。

## 检查

- Flutter 静态分析与 16 项测试：核心进程生命周期、导航/主题/草稿、窄窗口、延迟响应隔离、分页去重、三栏保存、折叠隐藏、启动就绪和资源失败降级。
- Rust 19 项单元/模拟集成测试。
- 默认 4 项旧源码静态检查；没有运行酒狐完整互动检查。
- GUI 使用独立测试账号、模拟消息/用量与未连接的 OneBot；不读取旧安装数据，不请求实际模型，不注册自动启动。
