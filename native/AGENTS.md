# 原生迁移协作约定

- 本目录是 Flutter＋Rust 迁移的业务核心，Slint 仅保留为酒狐候选验证。所有后续改动推送到 `Rust+Slint`，不向 main 合并或新建 Release，除非用户另行要求。
- 不启动 Node/Electron/WebView 作为原型运行依赖，不部署或覆盖旧客户端。
- 默认数据目录独立于旧客户端；旧 SQLite/V8 BLOB 不能未经迁移直接打开。
- 用户自带 QQ；只面向 OneBot/SnowLuma。网络接入和发送行为必须明确，测试使用模拟事件，不向实际 QQ 或模型发请求。
- Minecraft 酒狐首次默认关闭。只有可用硬件 GPU、实际渲染能力检查及已完成的渲染器同时满足才能启用。普通界面允许软件渲染。
- 检查使用 cargo fmt、cargo test --locked 和原生窗口定点验证；保持 Cargo.lock。功能未迁移时明确注明，不用占位数据冒充真实状态。
- 用户最终运行无需 Rust 工具链，但打包前必须检查动态库、素材与许可证，未验证前不宣称安装包开箱即用。

- 当前迁移契约：自动回复首次关闭，每会话一个运行任务和一个合并事件，账号写入/发送独立；发送结果不明不重试。模型每次成功返回的用量即时记录，工具后失败不丢计费；首轮无副作用才可故障备选。Windows 凭据 DPAPI 落盘，不把明文写配置。官方 JSON 导入必须用户明确选文件并确认，事务回滚/幂等，原件不改；不是旧库完整迁入。外部 SnowLuma 使用其自带运行时是 OneBot 边界，不把 Node 带回 QQAF 业务层。酒狐仍排除。

- 2026-10-09最新授权：0.1 干净安装包与资源交付完成后，用户要求新建并转到 `RS0.2.0`；此后开发和 push 使用 RS0.2.0，覆盖此前固定 Rust+Slint 的分支限制。目标是恢复全部功能（酒狐排除），README 最上方使用 Resonance SVG 和版本说明；不能把计划或占位控件宣称成执行成功。Rust+Slint 保留 0.1 构建源，不合并 main，不自动 Release。
