QQ ARC 是基于 [QQ Agent](https://github.com/Kondius/qq-agent) 开发的 Windows 桌面衍生项目。它保留 QQ Agent 的聊天、模型调用、人设、记忆、搜索与扩展能力，并围绕日常使用体验改进界面、首次配置、多账号管理和数据隔离。

相比原版，QQ ARC 进一步提供账号独立存储、可配置的跨聊天空间记忆共享、表情收藏共享与独立模式、全局管理员设置，以及更清晰的提醒管理和消息发送控制。

## 功能概览

### 界面与个性化

- 重新设计桌面标题栏、侧栏、仪表盘和设置导航。
- 默认与 Minecraft 主题，支持亮色、暗色及跟随系统。
- 可配置背景、字体、音效和动效；主题包支持资源与配色扩展。想制作自己的主题？查看[主题制作指南（Wiki）](https://github.com/N1v4lis/QQ-ARC/wiki/Theme-Authoring)。
- 仪表盘连接状态自动刷新，日志默认折叠；会话、记忆和存档提供刷新入口。
- 内置 GitHub 问题反馈入口。

### 多账号、记忆与数据

- 多个 QQ 账号分别绑定运行上下文、模型、人设、消息、记忆和提醒。
- 账号核心数据统一使用 `accounts/<uin>/account-storage.sqlite`，配合 SQLite WAL 与写入 Worker 持久化。
- 应用全局偏好与账号私有数据分开管理；异步任务使用明确账号身份。
- 记忆支持检索、上下文预算、修订及遗忘状态，并可配置聊天空间之间的共享规则。
- 表情收藏默认按账号独立保存；可切换到共享库，或显式复制收藏到选定账号。
- 切换表情模式不会自动合并、覆盖或删除已有收藏。
- 新统计按账号及会话记录；无法区分账号的旧统计单独标记为历史汇总。
- 默认数据目录为程序目录旁的 `arc-data/`，支持显式选择自定义位置。

对比基于 QQ Agent **0.4.0** 与 QQ ARC **0.4.6**。表中“——”表示本次对照中未确认原版提供对应功能，不代表对上游所有版本的结论。

| --- | --- | --- |
| QQ 群聊与私聊 | 支持 | 保留，并改进账号隔离与设置入口 |
| @、关键词与概率回复 | 支持 | 保留，增加全局管理员策略 |
| 模型与提供商配置 | 多提供商、模型列表、测试与价格配置 | 保留，并接入首次引导与常用供应商快捷配置 |
| 视觉与联网搜索 | 支持 | 保留 |
| 人设与聊天独立设置 | 支持 | 保留并改进绑定、引导与群聊快捷操作 |
| 长期记忆 | 群友印象、编辑与整理 | 扩展为结构化存储、检索、修订及遗忘状态 |
| 跨聊天空间记忆共享规则 | —— | 可配置来源、目标与共享范围 |
| 会话、存档与用量 | 会话记录、消息存档，按天／会话／模型统计用量与成本 | **WIP**：在原版基础上改进界面刷新、账号隔离与统计展示，完整功能仍需测试是否正常工作 |
| 定时提醒 | 模型可创建、查询和取消提醒 | **WIP**：增加设置页管理与多账号调度，当前功能不完全 |
| 表情收藏与发送 | 支持 | 增加独立库、共享库及显式复制 |
| 多 QQ 账号运行时隔离 | —— | 按账号绑定模型、人设、历史、记忆和提醒 |
| 管理员全局白名单策略 | —— | 可选启用，仍遵守回复概率与其他安全边界 |
| 首次启动引导 | 设置页配置 | 六阶段 OOBE，集中引导连接、人设、记忆与模型配置 |

| 界面主题 | 明暗与跟随系统 | 重新设计界面，增加 Minecraft 及主题资源扩展 |
| 账号存储 | 主要使用 JSON 文件 | 账号核心数据使用 SQLite，并区分全局与账号数据 |
| 更新检测 | 原项目更新源 | QQ ARC Releases |
| Token 消耗优化 | 事件驱动与上下文控制 | 开发中（WIP） |

## 开始使用

### 选择安装方式

| 安装方式 | 下载与使用 |
| --- | --- |
| 安装版 EXE | [下载安装包](https://github.com/N1v4lis/QQ-ARC/releases/download/v0.4.6/QQARCFOX-0.4.6-win-x64-Setup.exe)，双击安装；仅支持全新安装 |
| 便携版 ZIP | [下载便携版](https://github.com/N1v4lis/QQ-ARC/releases/download/v0.4.6/QQARC-0.4.6-win-x64-Portable.zip)，完整解压后运行 `QQ ARC/QQARC.exe` |
| 干净源码 ZIP | [下载当前版本源码](https://github.com/N1v4lis/QQ-ARC/releases/download/v0.4.6/QQARC-0.4.6-Source.zip)，供阅读与开发，不含用户数据与运行依赖 |

详细说明与 [SHA256 校验清单](https://github.com/N1v4lis/QQ-ARC/releases/download/v0.4.6/SHA256SUMS.txt) 见 [v0.4.6 RC Release](https://github.com/N1v4lis/QQ-ARC/releases/tag/v0.4.6)。安装版与便携版均包含 SnowLuma 1.14.22，首次启动从零配置。

1. 获取 QQ ARC 0.4.6 RC 的 Windows 安装包，安装到新的独立目录。
2. 启动 `QQARC.exe`，按照首次引导完成 QQ 与 SnowLuma 连接及密码修改。
3. 配置人设、记忆和模型 API，明确选择允许回复的聊天范围。
4. 在设置中调整模型、聊天白名单、发送间隔和管理员；定时提醒管理仍为 WIP。

需要帮助或遇到问题，请前往 [GitHub Issues](https://github.com/N1v4lis/QQ-ARC/issues)，描述操作步骤、预期行为和实际结果；请勿公开 API Key、Token、密码或私人聊天记录。
